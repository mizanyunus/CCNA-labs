# CCNA-labs
Lab Jaringan CCNA mencakup praktik konfigurasi, pengujian, dan troubleshooting jaringan Cisco menggunakan Packet Tracer. Materi meliputi IPv4/IPv6, subnetting, VLAN, trunking, STP, EtherChannel, inter-VLAN routing, static dan dynamic routing, DHCP, NAT, ACL, serta konfigurasi dasar keamanan perangkat Cisco.
